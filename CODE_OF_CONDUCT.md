# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there. It applies to everyone who takes part in MergeStory.

## What it means here

- Be kind and respectful. Disagree with the idea, not the person.
- Assume good intent. Ask questions before you judge.
- Help newcomers. Everyone started somewhere.
- No harassment, insults or discrimination, in issues, pull requests, reviews or any other space of
  the project.

The maintainers may remove comments, close threads or block people who break these rules.

## How to report a problem

Report it privately through GitHub's private vulnerability reporting: open the Security tab of the
repository and choose "Report a vulnerability". Only the maintainers can see the report. Please say
what happened and where. We will treat the report as private.
