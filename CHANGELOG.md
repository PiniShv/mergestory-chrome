# Changelog

All notable changes to MergeStory for Chrome are listed here, newest first.

## 0.1.1

- The video now plays for a comment with its own wording. Before, only the standard link text
  ("Watch the 2-minute MergeStory") was recognised. Now a YouTube or Google Drive link on a pull request
  page plays in place when the comment or description around it names MergeStory.

## 0.1.0

- A click on the MergeStory link in a GitHub pull request plays the video in the comment.
- Plays videos published to YouTube and Google Drive. Other links open as before.
- Nothing loads from a video host until you click.
